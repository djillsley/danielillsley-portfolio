# Portfolio Project: Daniel J Illsley

## Context
Daniel is a Strategic Technical Leader (CRM, Data, AI) seeking remote leadership roles. This portfolio showcases 13+ years of experience and specialized work in AI automation and autonomous agents.

## Technical Stack
- **Framework**: React (TypeScript) via Vite.
- **Routing**: `react-router-dom` (SPA with deep-linking).
- **Icons**: Lucide-React.
- **Styling**: Bespoke Vanilla CSS (`index.css`) with a professional dark charcoal and green theme.
- **Navigation**: URL-based navigation (/experience, /ai-lab, /data-strategy, /contact).
- **Contact**: Integrated JotForm script (`260646553132050`).

## Design Standards
- **Color Palette**: 
  - Background: `#171717` (Charcoal)
  - Card BG: `#262626`
  - Accent: `#22c55e` (Green)
  - Text: `#f5f5f5` (Main), `#a3a3a3` (Muted)
- **UI Patterns**: 
  - Collapsible `JobCard` components.
  - Custom React-based **Cohort Retention Heatmap** (Data & Strategy tab).
  - Professional SVG icons for Qualifications.
- **Spelling**: British English (e.g., "Organiser", "Optimisation").

## Deployment & Hosting
- **Platform**: Netlify (https://daniel-illsley.netlify.app/).
- **SPA Config**: `_redirects` file in `public/` maps all routes to `index.html`.
- **Credits**: Current Netlify model consumes 15 credits per production deploy (300/mo limit).
