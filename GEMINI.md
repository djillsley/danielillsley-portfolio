# Portfolio Project: Daniel J Illsley

## Context
Daniel is a Strategic Technical Leader (CRM, Data, AI) seeking remote leadership roles. This portfolio showcases 13+ years of experience and specialized work in AI automation and autonomous agents.

## Technical Stack
- **Framework**: React (TypeScript) via Vite.
- **Animations**: `framer-motion` (page transitions, layout shifts).
- **Routing**: `react-router-dom` (SPA with deep-linking).
- **Icons**: Lucide-React.
- **Styling**: Bespoke Vanilla CSS (`index.css`) with Glassmorphism and responsive design.
- **Interactive**: HTML5 Canvas (Interactive Data Node Background).
- **Contact**: Integrated JotForm script (`260646553132050`).

## Design Standards
- **Color Palette**: 
  - Background: Deeper Black `#0a0a0a` (for higher contrast)
  - Card BG: Glassmorphic `#171717` with blur.
  - Accent: `#22c55e` (Green)
  - Text: `#f5f5f5` (Main), `#a3a3a3` (Muted)
- **UI Patterns**: 
  - **Interactive Background**: Canvas-based data node network.
  - **Modals**: High-resolution project previews for AI/Data case studies.
  - **Visualisations**: Custom React components for Data Lab blocks (Pipeline flow, ROI charts, Sampling diagrams, RFV matrices).
  - **Quick Jump**: Section-based anchor navigation on the Experience page.
- **Consistency**: Unified `ProjectCard` style across all pages.
- **Spelling**: British English (e.g., "Orchestration", "Optimisation").

## Deployment & Hosting
- **Platform**: Netlify (Linked to GitHub for CI/CD).
- **Source Control**: GitHub (`djillsley/danielillsley-portfolio`).
- **Branching Strategy**: 
  - `main`: Production (Live Site).
  - `develop`: Staging/Previews (Safe iteration).
- **Privacy**: Git history scrubbed; using GitHub no-reply email for all commits.
